# .github

Organisation defaults for every Marion-s-Kitchen-Group repository. GitHub uses these files in any repo that has no file of its own type.

| File | Purpose |
|---|---|
| `profile/README.md` | Public organisation profile |
| `SECURITY.md` | How to report a vulnerability |
| `CONTRIBUTING.md` | Branches, pull requests, commits, AI agents |
| `.github/ISSUE_TEMPLATE/` | Bug and task forms |
| `.github/pull_request_template.md` | Default pull request checklist |

This repository is public: never put store data, credentials or internal URLs here.
